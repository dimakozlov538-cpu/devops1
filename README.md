## Part 1. Инструмент **ipcalc**

- ipcalc: 
- Определяет адрес сети по заданному IP и маске (например, для 192.168.100.10/16 → сеть 192.168.0.0).
- Показывает широковещательный (broadcast) адрес.
- Находит первый и последний доступные хосты в подсети.
- Переводит маски между форматами:
префикс (/24) ↔ десятичная (255.255.255.0) ↔ двоичная (11111111.11111111.11111111.00000000).
- Проверяет, принадлежит ли IP к частной или публичной сети.
- Выводит двоичное представление IP и маски, разделяя сетевую и хостовую части.

## Part 3. Утилита **iperf3** (измеряет скорость соединения)

#### 3.1. Скорость соединения

Немного теории:

1 MB (мегабайт) - 8 Mb (мегабит)
1 KB (килобайт) - 8 Kb (килобит)
1 B (байт) - 8 b (бит)

Верно только для скорости сети:
1 MB = 1000 KB
1 KB = 1000 B

1 Mb = 1000 Kb
1 Kb = 1000 b

В операционных системах и хранилищах (файлы, RAM, диски) используется двоичная система:
1 MiB = 1024 KiB
1 KiB = 1024 B

##### Перевод: 
8 Mbps = 1 MB/s\
100 MB/s = 800.000 Kbps\
1 Gbps = 1000 Mbps

![alt text](images/5_12.png)

- Traceroute определяет путь к целевому узлу, отправляя серию пакетов с увеличающимся значением TTL (Time To Live). Первый пакет с TTL=1 встречает первый маршрутизатор, который возвращает ICMP сообщение об ошибке. Traceroute отмечает адрес маршрутизатора и время ответа. Повторяя отправку с увеличенным TTL, traceroute продолжает следовать за пакетом до его достижения целевого узла, считая процесс завершенным при получении ответа от него.
